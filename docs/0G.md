# 0G Integration: Decentralized AI Compute & Storage

AegisNet integrates **0G (Zero Gravity)** to provide verifiable, TEE-attested AI strategy planning and tamper-proof decentralized audit trails for autonomous DeFi agents.

---

## 1. Prior state

* **Baseline commit:** [`ec4befe`](https://github.com/shriyashsoni/aegisnet/commit/ec4befe)
* **Date:** 2026-10-19

At baseline commit `ec4befe`, the repository was an early prototype centered on simulated Midnight dual-ledger ZK proofs and mock SwapVM execution. It lacked decentralized compute, had no immutable audit logging, relied on centralized or rule-based fallback planners without verifiable hardware attestation, and lacked integration with 0G Private Compute or the 0G Storage network.

## 4. What breaks if 0G is removed

If 0G is removed, autonomous agents lose both verifiable TEE-attested strategy execution and tamper-proof decentralized audit storage, forcing the protocol to fail safe and block all trade proposals.

---

## 5. What's next

1. **Direct Smart Contract Attestation Verification:** Integrate onchain verification of 0G TEE hardware quotes directly inside `AegisExecutionManager.sol` so contracts can cryptographically verify that calldata was synthesized inside a secure enclave before allowing execution.
2. **0G Key-Value (KV) Layer Integration:** Utilize 0G KV streams for low-latency, version-aware agent session states and dynamic portfolio risk parameters alongside the append-only log layer.
3. **Decentralized Provider Marketplace Routing:** Enable agents to dynamically discover and bid on GPU provider nodes across the 0G network based on latency budgets, cost optimization, and cryptographic trust levels.
