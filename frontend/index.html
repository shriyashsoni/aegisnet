How it works

Four phases, one request.

An agent asks to act. AegisNet checks who it is, builds the route, decides if a human must sign off, then settles it onchain.

  1. I

    0G AI Strategy Planning

    The agent formulates execution parameters in 0G Private Compute (TEE-attested AI), verifying liquidity and quoting before proposing onchain.

  2. II

    Onchain Limit Check

    AegisExecutionManager verifies that the agent is active, the adapter is whitelisted, and the trade fits within daily spend limits.

  3. III

    World ID Agent Pass

    Trades at or above the threshold hold onchain pending human approval. The owner clears via World ID Agent Pass, issuing a relayer attestation.

  4. IV

    Uniswap V3 & 0G Storage

    Once cleared, the manager settles the swap atomically on Uniswap V3 (SwapRouter02) and commits an immutable decision audit record to 0G Storage.

Why AegisNet

Autonomy for agents. Control for owners.

Agents with a raw private key can do anything. AegisNet gives each agent a named identity with hard limits, and brings a verified human in exactly when the stakes are high.

Scoped agent identity

Every agent is registered to its operating address with daily spend limits and whitelists owned by you. Revoke it onchain and the agent is immediately deactivated.

FAQs

Questions, answered.

What stops an agent from draining a wallet?
Three onchain checks. AegisExecutionManager rejects any request from an agent that is not registered and active, or that targets an unwhitelisted contract. Orders at or above the approval threshold wait for World ID Agent Pass human authorization. Daily spend limits are strictly enforced onchain when transactions settle.
What occurs when a request exceeds the threshold?
The request is held onchain in a pending state. The owner authorizes the trade through the World ID Agent Pass. The relayer verifies the human credential and issues a cryptographic attestation with a single-use nullifier, allowing the manager to execute the trade on Sepolia without replay risk.
Can I stop a request that is already pending?
Yes. The agent owner, the agent address, or the protocol admin can call cancelExecution on any pending request before it executes. In the console, this is a single click from the Activity feed.
Can I change an agent's limits later?
Yes. You can update daily spending limits, modify the approval threshold, reconfigure allowed contract targets, or deactivate the agent registration entirely onchain.
Who signs the transactions?
You do. Registering agents, updating limits, executing swaps, and cancelling orders are all signed directly by your wallet on Sepolia. The backend never holds private keys for users.
Which networks are supported?
Execution settlements and Uniswap V3 swaps run on Ethereum Sepolia. Audit trail decision records are stored on the 0G Galileo testnet, with AI planning powered by 0G Private Compute TEEs.
How does the World ID Agent Pass work?
When a trade exceeds the configured threshold, execution is held. The human operator authenticates via World ID Agent Pass. The backend validates the proof server-side and issues an ECDSA relayer attestation with a single-use nullifier that unlocks execution on AegisExecutionManager.
